ℹ️ Comment fonctionnent les points ?

Responsabilité principale de la semaine : ⭐ +2 quand elle est faite.
Tortues : ⭐ +1 pour la personne responsable cette semaine.
Salle de jeux, chambres et routine du soir : suivi visuel uniquement, 0 point, afin de ne pas avantager automatiquement les enfants dans le classement familial.
Comportement : un parent peut ajouter ou retirer des points manuellement. Le défi « repas sans cris » donne +1 à chacun.

🚀 Mise en service

Objectif : après la configuration initiale du projet, un nouvel appareil ne devra plus saisir l’URL Supabase, la clé publique ni un code technique.
1. Configurer Supabase une seule fois côté déploiement.
2. Créer le compte d’un parent et la famille.
3. Ajouter Angela/Yvan comme parents et Solé/Calista comme profils enfants.
4. Sur un nouvel appareil : « Rejoindre ma famille » via invitation/QR (prochaine étape backend).
Le guide complet est fourni avec cette version. Les invitations/QR nécessitent les nouvelles tables Supabase et seront activées après la configuration du backend.

🛠️ Configuration administrateur Supabase

Cette zone est temporaire et réservée à la mise en service. Dans la version finale, les appareils rejoindront la famille via compte/invitation et cette configuration technique disparaîtra de l’usage courant.
